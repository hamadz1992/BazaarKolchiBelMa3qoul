# Dashboard

الواجهة الحالية هي مرحلة تثبيت تصميم شاشة «النظرة العامة» قبل ربطها ببيانات حقيقية.

مرجع التصميم: الصورة التي قدمها المستخدم.

قواعد المرحلة:
- الحفاظ على RTL.
- عدم إضافة وظائف تجارية غير مطلوبة.
- عدم استخدام بيانات ثابتة عند بدء ربط قاعدة البيانات.
- أي تغيير بصري لاحق يكون عبر Commit مستقل.
